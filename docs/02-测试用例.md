## 1. 测试目标

验证以下五类质量，覆盖需求和边界：

1. **算得对**：默认费率、分钟累计、午休冻结、下班满额、周末为零。
2. **切得准**：未上班、上午、午休、下午、已下班、休息日之间的状态和边界时间准确。
3. **设得稳**：所有参数可设置、可校验、可持久化，坏配置不导致崩溃。
4. **看得清**：深色玻璃卡片界面无裁切、层级清楚，倒计时和金额刷新节奏符合预期。
5. **跑得起来**：输出单文件 Windows exe，无需管理权限和网络，双击可用。

---

## 2. 测试策略

| 层级 | 方法 | 范围 |
|---|---|---|
| 自动化单元测试 | 自写 C# 控制台测试程序，固定时钟调用核心计算 | 计算、状态、格式化、参数校验、配置序列化 |
| 自动化快速验证 | 构建后直接运行测试程序，检查退出码 | 全部自动化用例 |
| 手动 UI 测试 | 启动测试构建（可注入固定时间）和正式 exe | 布局、动画、置顶、拖拽、设置页、DPI |
| 打包冒烟测试 | 在干净目录双击运行最终 exe | 单文件、无控制台、配置落盘、无网络 |

> 测试构建可固定“当前时间”，仅用于覆盖不同时段的状态。**交付 exe 永远读取系统本地时间，不包含改系统时间的入口。**

### 3.3 默认参数与期望费率

```text
月薪 S              = 33,500.00
月计薪天数 D         = 21.75
上班                 = 09:30
午休                 = 12:30 – 14:00
下班                 = 19:00
每日有效分钟 M       = 180 + 300 = 480
日薪                 = 33,500 / 21.75       = 1,540.229885…
分钟薪               = 1,540.229885… / 480  = 3.208812260…
时薪                 = 3.208812260… × 60    = 192.528735…
```

| 12:30 已赚（180 分钟） | ¥577.59 |
| 19:00 满额（480 分钟） | ¥1,540.23 |

### 3.4 优先级定义

- **P0**：核心工资/状态计算、默认值、设置保存、exe 可运行、置顶。未通过则不得交付。
- **P1**：重要交互、持久化回退、DPI、错误提示。应在交付前通过。
- **P2**：体验细节、边缘显示、非关键兼容性。允许带记录交付。
