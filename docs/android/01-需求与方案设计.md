# Android 版需求与方案设计

- 版本：v1.2.0（versionCode 4）
- 日期：2026-11-14
- 对应 Windows 版：v1.2.0
- 包名：`com.salarymonitor.app`
- 产物：`dist/薪资显示器-Android.apk`

## 1. 目标

把 Windows 版“薪资显示器”的核心能力带到 Android 手机：按分钟累计今日工资、显示今日进度、距离下班倒计时，并允许用户修改月薪、月计薪天数和工作时间。

v1.1.0 增加“按当月实际工作日计薪”：内置 2026—2027 年国务院节假日与调休表，按当月实际工作日数计算日薪，并识别法定节假日和调休上班日。

v1.1.1 是界面修复版本：顶部品牌图标不再直接复用 Android 自适应启动图标，改用独立的透明圆角位图资源，去掉图标四角的方形深色底/黑框。计算、配置、默认值和权限均不变。

v1.2.0 增加首页金额隐私显示：在“今日已赚”右侧放置小眼睛按钮，点击后主金额显示为 `••••••`，日薪、时薪、分钟薪显示为 `¥••••`；再次点击恢复。隐藏状态保存在应用私有配置中，重启后保持，默认显示。

Android 版不是 Windows 界面的逐像素移植，而是同一套信息与计算规则在手机竖屏上的重新排布。

## 2. 平台差异与取舍

| Windows 能力 | Android 处理 |
| --- | --- |
| 窗口置顶 | Android 没有等价的普通应用窗口置顶能力。v1.1.0 改为**全屏仪表盘 + 屏幕常亮**，适合放在桌面/支架上查看 |
| 无边框窗口拖动 | 手机系统窗口由系统管理，不提供拖动 |
| 最小化/关闭按钮 | 使用系统返回/最近任务；主页只保留设置入口 |
| 鼠标悬停提示 | 移除，改为直接可见的说明文字 |
| 桌面快捷方式 | 使用 Android 启动器图标 |
| 本地 JSON 配置 | 使用应用私有 `SharedPreferences`，不申请存储权限 |

后续如需更接近“置顶”的体验，可单独增加：

1. 通知栏常驻薪资（需要通知权限 + 前台服务）；
2. 桌面悬浮窗（需要 `SYSTEM_ALERT_WINDOW` 特殊权限）。

这两项不进入当前版本，避免首次安装就要求敏感权限。

## 3. 功能范围

### 3.1 今日仪表盘

- 今日已赚金额，按“已完成整分钟”累计，金额四舍五入到 2 位小数。
- 日薪、时薪、分钟薪。
- 当前状态：周末休息 / 节假日休息 / 未上班 / 上午工作中 / 午休中 / 下午工作中 / 今日已下班。
- 距离上班或距离下班的倒计时（秒级刷新）。
- 今日进度、已完成分钟 / 总有效分钟。
- 当前日期、星期、时分秒。
- 剩余有效工时。
- 午休期间金额冻结；下班后金额封顶；休息日不计薪。
- 实际工作日模式下，法定节假日不计薪，调休上班日按工作日计薪。
- 今日已赚右侧的小眼睛按钮：切换主金额和三项费率的显示/遮挡，隐藏状态持久化。

### 3.2 设置

- 月薪（元）。
- 月计薪天数（平均模式）。
- **按当月实际工作日计薪**开关：
  - 关闭：沿用 21.75 天平均，仅周六、周日休息。
  - 开启：日薪 = 月薪 ÷ 当月实际工作日数；自动识别 2026—2027 年法定节假日和调休上班日；隐藏平均天数输入。
  - 设置页显示当前月份和实际工作日数；其他年份回退为周一至周五。
- 上班时间、午休开始、午休结束、下班时间，使用 24 小时制时间选择器。
- 每日有效工时与日薪/分钟薪实时预览。
- 屏幕常亮开关，默认开启。
- 恢复默认值、取消、保存。
- 保存前校验：金额/天数范围、时间范围、时间先后顺序。
- 保存失败时给出可读错误，不崩溃。

### 3.3 本地化

- 界面语言：简体中文。
- 金额格式：`¥1,540.23`，千分位，2 位小数，四舍五入（half-up）。
- 时间格式：24 小时制 `HH:mm` / `HH:mm:ss`。
- 日期格式：`11月5日 · 周三`。

## 4. 非目标

- 不包含 2026—2027 年之外的官方节假日/调休表；其他年份按周一至周五回退。
- 不包含月度累计、年终奖、个税、社保、请假、加班。
- 不包含账号、云同步、网络请求、广告、统计 SDK。
- 不包含通知栏常驻、桌面小组件、悬浮窗。
- 不包含应用商店上架、Google Play 签名、企业 MDM 分发。
- 不主动读取通讯录、位置、存储等敏感权限。

## 5. 计算规则

平均模式与 Windows 版保持一致：

```text
日薪     = 月薪 / 月计薪天数
总分钟数 = (午休开始 - 上班) + (下班 - 午休结束)
分钟薪   = 日薪 / 总分钟数
今日已赚 = 日薪 × 已完成整分钟 / 总分钟数
```

实际工作日模式：

```text
当月实际工作日 = 当月周一至周五
                 - 法定节假日落在工作日的天数
                 + 国务院安排的周末调休上班日
日薪           = 月薪 / 当月实际工作日
分钟薪         = 日薪 / 总分钟数
今日已赚       = 0（法定节假日/周末）
               = 日薪 × 已完成整分钟 / 总分钟数（工作日/调休上班日）
```

默认值：

```text
月薪        33,500.00 元
月计薪天数  21.75 天
上班        09:30
午休开始    12:30
午休结束    14:00
下班        19:00
日薪        ¥1,540.23
分钟薪      ¥3.21
总有效分钟  480
```

实际工作日模式示例（2026 年 11 月，21 个工作日）：

```text
日薪    = 33,500 ÷ 21 ≈ ¥1,595.24
分钟薪  = 1,595.238… ÷ 480 ≈ ¥3.32
```

逐月工作日数和完整日历见 [2026—2027 日历与工作日](04-2026-2027日历与工作日.md)。

计薪边界：

- 09:30:00 为 0 分钟；09:30:59 仍为 0 分钟；09:31:00 为 1 分钟。
- 12:30:00–13:59:59 金额冻结在 180 分钟。
- 14:00:00 仍为 180 分钟；14:01:00 为 181 分钟。
- 19:00:00 达到 480 分钟，金额封顶。
- 平均模式仅周六、周日视为休息日；周五正常计薪。
- 实际工作日模式按内置 2026—2027 节假日/调休表判断工作日；节假日当天 0 分钟、¥0.00，调休周末正常计薪。

## 6. 界面设计

### 6.1 视觉

- 深色夜空背景：`#071019` 到 `#0A1A24`，叠加青色/靛蓝径向微光。
- 主色：青色 `#67E8F9`、青绿 `#2DD4BF`、靛蓝 `#818CF8`、琥珀 `#FBBF24`。
- 主文字 `#F8FAFC`，次级 `#94A3B8`，弱化 `#64748B`。
- 大金额使用白到浅青渐变，状态胶囊使用低透明度同色系背景。
- 进度条为青→青绿→靛蓝渐变，圆角。
- 背景/卡片/按钮均使用自绘 drawable，不依赖 Material Components 或第三方 UI 库。

### 6.2 仪表盘结构

从上到下：

1. 品牌行：应用图标（独立透明圆角位图，40dp）、名称、`SALARY MONITOR`、设置按钮。
2. 状态行：状态胶囊 + 日期/时钟。
3. `今日已赚` + `按分钟累计` 标签 + 右侧小眼睛按钮。
4. 大金额（隐藏时为 `••••••`）。
5. 日薪 / 时薪 / 分钟薪三列。
6. 倒计时卡片：距离下班、下班时间、剩余有效工时。
7. 进度条与分钟数。
8. 底部说明：按 21.75 天平均或按本月 N 个工作日估算 + 更新频率。

小屏（如 320dp 宽）允许纵向滚动；金额超过 9 个字符时自动缩小字号，避免溢出。

### 6.3 设置结构

1. `PREFERENCES` / `设置` / 说明。
2. 收入参数卡片：
   - 月薪；
   - “按当月实际工作日计薪”开关；
   - 平均模式显示月计薪天数输入；实际模式隐藏该输入，并显示当月实际工作日与数据来源提示；
   - 实时日薪/分钟薪摘要。
3. 工作时间卡片：4 个时间字段、每日有效工时摘要。
4. 显示卡片：屏幕常亮开关 + Android 平台说明。
5. 固定底部操作栏：恢复默认、取消、保存。
6. 校验失败时显示红色错误条，并标记对应输入区域。

时间字段点击打开系统 24 小时 `TimePickerDialog`，避免手机键盘输入时间格式错误。

## 7. 技术方案

### 7.1 技术栈

- 原生 Android（Java），不引入 AndroidX、Kotlin、Flutter、React Native。
- `minSdk 26`（Android 8.0），`targetSdk 34`（Android 14）。
- 单 Activity 仪表盘 + 单 Activity 设置页。
- 纯 `Activity` + 原生 View/XML 布局。
- 构建：JDK 17 + Android SDK Build-Tools 34.0.0 + `aapt2` / `javac` / `d8` / `zipalign` / `apksigner`，不依赖 Gradle 和网络依赖。

选择原生 Java 的原因：当前机器没有 Android Studio/Gradle，原生方式可以用最小的官方工具链直接产出 APK；同时避免引入需要额外下载的依赖。

### 7.2 代码结构

```text
android/
  app/
    AndroidManifest.xml
    res/                       # 颜色、样式、drawable、布局、图标
      drawable-*dpi/header_icon.png  # 顶部透明圆角图标，避免自适应图标方形底色
    src/com/salarymonitor/app/
      MainActivity.java        # 仪表盘、秒级刷新、状态配色
      SettingsActivity.java    # 设置、时间选择、校验、保存
      core/                    # 纯 Java 计算层，可在 JVM 上测试
        AppSettings.java
        DayKind.java          # 工作日/调休/周末/节假日
        DayPhase.java
        WorkSchedule.java
        WorkdayCalendar.java  # 2026—2027 官方节假日与调休表
        PayCalculator.java
        PaySnapshot.java
        Formatters.java
        SettingsValidator.java
        PhaseText.java
      data/SettingsRepository.java
      ui/GradientTextView.java
      ui/ProgressBarView.java
  tests/CoreTests.java         # 70 个纯 JVM 测试
  build.ps1                    # 编译、dex、签名、校验
  signing/                     # 本地签名密钥（不进入 APK）
```

### 7.3 数据存储

`SharedPreferences` 文件名 `salary_monitor`，键：

```text
monthly_salary, monthly_work_days,
actual_workdays_enabled,
work_start_minutes, lunch_start_minutes, lunch_end_minutes, work_end_minutes,
keep_screen_on, version
```

- 金额和天数保存为十进制字符串，避免 `double` 精度问题。
- 读取时做校验；配置损坏/越界时回退默认值。
- 保存使用 `commit()`，能捕获失败并向用户提示。
- 配置只存在应用私有目录，不申请存储权限。

### 7.4 刷新策略

- 仪表盘在前台时由主线程 `Handler` 每秒刷新。
- `onResume` 立即刷新并重新读取设置；`onPause` 停止回调，避免后台耗电。
- 设置页返回时刷新仪表盘并重新应用屏幕常亮。
- 应用没有网络、没有后台服务；不承诺锁屏/杀进程后的持续更新。

### 7.5 兼容性

- 最低 Android 8.0（API 26），覆盖绝大多数在用 Android 手机。
- 固定竖屏，避免横屏时信息密度过低。
- 使用 `java.time`（API 26 原生支持）。
- 使用系统字体，中文由设备字体渲染；不内嵌字体文件。

## 8. 构建与签名

构建脚本：`android/build.ps1`

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\android\build.ps1
```

流程：

1. 用 JDK 17 编译纯 Java 核心测试并运行。
2. `aapt2 compile` 编译资源。
3. `aapt2 link` 生成基础 APK 与 `R.java`。
4. `javac --release 8` 编译应用源码。
5. `d8` 生成 `classes.dex`，加入 APK。
6. `zipalign` 对齐。
7. 使用本地自签名密钥 `android/signing/salarymonitor.jks` 签名。
8. `apksigner verify` 校验，并输出 SHA-256。

签名说明：

- 这是本地自签名 APK，不是 Google Play 签名。
- 后续升级必须使用同一把密钥；密钥保留在 `android/signing/`，不要删除。
- 首次安装需要在手机上允许“安装未知应用”。

## 9. 验收标准

- 默认值下日薪 `¥1,540.23`、分钟薪 `¥3.21`、总分钟 480。
- 实际工作日模式，2026 年 11 月日薪 `¥1,595.24`、分钟薪 `¥3.32`；2026 年 10 月按 18 天计算日薪 `¥1,861.11`。
- 09:30:59 金额为 0；09:31:00 变为 `¥3.21`（平均模式）或 `¥3.32`（2026 年 11 月实际模式）。
- 午休金额冻结；14:01 恢复累计。
- 19:00 金额为当天日薪，状态“今日已下班”。
- 平均模式周末金额为 0，状态“周末休息”。
- 实际模式法定节假日金额为 0，状态“节假日休息”；调休周末正常计薪。
- 设置修改后返回仪表盘立即生效，杀进程重开仍保留。
- 非法输入/时间顺序不保存，并显示错误。
- 顶部品牌图标四角透明，不出现自适应图标的方形深色底/黑框；图标圆角与外沿完整。
- 设置页“屏幕常亮”能即时影响下次返回仪表盘的窗口行为。
- APK 可安装、可启动、无崩溃；签名校验通过。
- 不申请网络、存储、位置、通讯录等权限。
